개요

콘텐츠는 OnBook 뷰어 안에서 iframe으로 실행됩니다. 뷰어와의 상호작용(페이지 이동, 파일 열기 등)은 모두 ob.viewer.api를 통해 이루어집니다.

ob.viewer.api는 콘텐츠 iframe의 window.ob.viewer.api에 자동으로 설정됩니다. NW.js(앱) 환경과 웹 환경 모두 동일한 방식으로 호출하면 됩니다.

API 카테고리

  • 페이지 이동 단원을 벗어나 다른 화면(교과서·콘텐츠·내 수업하기 등)으로 이동하거나 새 창을 열고, 이전 화면으로 돌아가는 등 전체 화면 이동을 담당합니다.
  • 단원 내 이동 현재 열려 있는 단원(콘텐츠 패키지) 안에서만 페이지를 이동하거나 페이지 정보를 조회합니다.
  • 시스템 로컬 파일·폴더 열기, 앱 실행, 다운로드를 수행합니다.

사용 방법

콘텐츠 HTML에 onbook.api.min.js를 포함하면 ob.viewer.api가 자동으로 준비됩니다. 별도의 초기화 없이 바로 호출하면 됩니다. 경로는 파일을 둔 위치 기준 상대경로이며, 아래는 예시입니다. 

<!-- 콘텐츠 HTML에 포함 (경로는 예시) -->
<script src="../js/ob/onbook.api.min.js"></script>
// 페이지 이동 예시
ob.viewer.api.goPageName("e5_01_01_01_01.html");
ob.viewer.api.goPage(8);

// 정보 조회 예시
const current = ob.viewer.api.getPageNum();
console.log("현재 페이지:", current);
goPage를 비롯한 페이지 관련 API(이동·조회)는 현재 열려 있는 단원(하나의 콘텐츠 패키지) 안에서만 동작합니다. 다른 단원으로 이동하려면 window.open으로 대상 단원을 여세요.

window.open

window.open( url, target, options ) 페이지 이동

교과서(ebook)·콘텐츠(contents)·내 수업하기(myclass) 화면으로 이동하거나 새 창을 열 때는 브라우저 표준 함수인 window.open을 그대로 사용합니다. OnBook 뷰어 환경에서는 window.open이 내부적으로 연결되어 있어 NW.js(앱)와 웹 환경에서 동일한 방식으로 호출하면 됩니다.

파라미터 타입 설명
url string 이동/오픈할 URL — 교과서·콘텐츠·내 수업하기 화면 URL 또는 임의의 html 파일 경로
target string "_top" · "_blank" · 창 이름
options object (선택) 창 옵션.
maximize: true — 새 창을 최대화한 크기로 엽니다. USB 버전·PC 설치 버전(NW.js 앱)에서 적용되며, 웹 환경에서는 무시됩니다.

url 쿼리 파라미터

화면 URL에 다음 쿼리 파라미터를 붙이면 콘텐츠가 열릴 때 특정 페이지로 바로 진입합니다.

파라미터 타입 설명
pageName string 진입할 페이지 파일명 — .html 확장자 포함. goPageName()과 동일한 값을 사용합니다.
page number 진입할 페이지 번호. goPage()와 동일한 값을 사용합니다.

사용 예시

// ① ebook 뷰어를 새 창(최대화)으로 열기 — page 번호로 진입 페이지 지정
window.open(
  "/scene/ebook/index.html?contentUrl=../../onbook/ebook/unit01/&page=5",
  "_blank",
  { maximize: true }
);
// ② contents 뷰어에서 다른 단원의 특정 페이지 열기 (현재 창에서 이동)
// pageName으로 진입 페이지 지정
window.open(
  "/scene/contents/index.html?contentUrl=../../onbook/contents/unit01/lesson02&pageName=e5_01_02_01_01.html",
  "_top"
);

// page 번호로 진입 페이지 지정
window.open(
  "/scene/contents/index.html?contentUrl=../../onbook/contents/unit01/lesson02&page=5",
  "_top"
);
// ③ 기타 html 파일(도움말, 팝업 등)을 새 창(최대화)으로 열기
window.open(
  "../popup/help.html",
  "_blank",
  { maximize: true }
);

historyBack

ob.viewer.api.historyBack() 페이지 이동

직전에 열었던 화면으로 돌아갑니다. 자료실·팝업 모듈의 닫기 버튼에 사용합니다. 

// 닫기 버튼 클릭 시
ob.viewer.api.historyBack();

goPage

ob.viewer.api.goPage( pageNumber ) 단원 내 이동

뷰어의 페이지를 지정한 번호로 이동합니다. 현재 열려 있는 단원 안에서만 이동합니다.

파라미터 타입 설명
pageNumber number 이동할 페이지 번호 
ob.viewer.api.goPage(5);  // 5페이지로 이동

goPageName

ob.viewer.api.goPageName( pageName ) 단원 내 이동

HTML 페이지 파일명(pageName)으로 뷰어 페이지를 이동합니다. 현재 열려 있는 단원 안에서만 이동합니다.

파라미터 타입 설명
pageName string 이동할 페이지 파일명 — .html 확장자 포함 
ob.viewer.api.goPageName("e5_01_01_01_01.html");
ob.viewer.api.goPageName("e5_01_02_03_01.html");

goPagePrev

ob.viewer.api.goPagePrev() 단원 내 이동

현재 페이지에서 이전 페이지로 이동합니다.

ob.viewer.api.goPagePrev();

goPageNext

ob.viewer.api.goPageNext() 단원 내 이동

현재 페이지에서 다음 페이지로 이동합니다.

ob.viewer.api.goPageNext();

goPageFirst

ob.viewer.api.goPageFirst() 단원 내 이동

첫 번째 페이지로 이동합니다.

ob.viewer.api.goPageFirst();

goPageLast

ob.viewer.api.goPageLast() 단원 내 이동

마지막 페이지로 이동합니다.

ob.viewer.api.goPageLast();

getPageNum

ob.viewer.api.getPageNum() 단원 내 이동

현재 뷰어에 표시 중인 페이지 번호를 반환합니다.

반환값: number — 현재 페이지 번호 
const page = ob.viewer.api.getPageNum();
console.log("현재:", page);

getPageNumFirst

ob.viewer.api.getPageNumFirst() 단원 내 이동

이 콘텐츠의 시작 페이지 번호를 반환합니다.

반환값: number — 시작 페이지 번호 
const first = ob.viewer.api.getPageNumFirst();

getPageNumLast

ob.viewer.api.getPageNumLast() 단원 내 이동

이 콘텐츠의 마지막 페이지 번호를 반환합니다.

반환값: number — 마지막 페이지 번호 
const last = ob.viewer.api.getPageNumLast();

getPageTotal

ob.viewer.api.getPageTotal() 단원 내 이동

전체 페이지 수를 반환합니다.

반환값: number — 전체 페이지 수 
const total = ob.viewer.api.getPageTotal();
console.log(`${ob.viewer.api.getPageNum()} / ${total}`);

openFolder

ob.viewer.api.openFolder( path ) 시스템

지정한 경로의 폴더를 탐색기(파일 관리자)로 엽니다. NW.js(앱) 환경에서만 동작합니다.

파라미터 타입 설명
path string 열 폴더 경로. 콘텐츠 기준 상대경로 또는 절대경로(/onbook/…) 
ob.viewer.api.openFolder("../../onbook/download/unit01/files");

openApp

ob.viewer.api.openApp( path ) 시스템

지정한 경로의 파일을 연결 프로그램으로 엽니다 (예: .hwp는 한글, .pdf는 PDF 뷰어, .exe는 실행). NW.js(앱) 환경에서만 동작합니다.

파라미터 타입 설명
path string 열 파일 경로. 콘텐츠 기준 상대경로 또는 절대경로(/onbook/…) 
ob.viewer.api.openApp("../../onbook/download/unit01/game.exe");

downloadFile

ob.viewer.api.downloadFile( path ) 시스템

지정한 경로의 파일을 다운로드합니다. NW.js(앱) 환경에서만 동작합니다.

파라미터 타입 설명
path string 다운로드할 파일 경로. 콘텐츠 기준 상대경로 또는 절대경로(/onbook/…) 
ob.viewer.api.downloadFile("../../onbook/download/unit01/document.hwp");

hideMyClassUi

ob.viewer.api.hideMyClassUi() 내 수업하기

「내 수업하기」 화면의 상단 UI를 숨깁니다. 콘텐츠를 넓게 보여줘야 할 때 사용합니다. 

ob.viewer.api.hideMyClassUi();

showMyClassUi

ob.viewer.api.showMyClassUi() 내 수업하기

숨긴 상단 UI를 다시 표시합니다.

ob.viewer.api.showMyClassUi();
「내 수업하기」 화면에서만 동작합니다. 숨긴 뒤에는 반드시 다시 표시해 주세요.
